# 저장소 작업 지침

- 작업을 시작하기 전에 [CONTRIBUTING.md](CONTRIBUTING.md)의 Git 및 이슈 작성 규칙을 따릅니다.
- 새 이슈와 기존 이슈 수정 모두 표준 양식을 사용합니다. 본문은 제목, 브랜치, 작업 목적, 주요 작업 내용, 완료 기준 순서로 작성합니다.
- 이슈 생성 후 실제 번호를 브랜치명에 반영하고 본문을 갱신합니다.
- 완료 기준은 실제로 완료하고 확인한 항목만 체크합니다. 작업 종료 시 최종 구현 범위와 완료 상태를 이슈에 반영합니다.
- 사용자 지시가 이 문서나 저장소 규칙과 충돌하면 사용자 지시를 우선합니다.
