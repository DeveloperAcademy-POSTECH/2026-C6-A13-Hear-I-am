# iPhone 17 POC 인수 시험

동행자가 실제 위치와 수동 걸음 수를 기록합니다. 평탄하고 통제된 실내에서 배 앞 세로/화면 바깥쪽으로 단단히 고정합니다. 앱은 전면 유지합니다. 첫 시험의 목적은 센서·방향 부호·사용 흐름 확인입니다.

| 시험 | 수행 | 확인/기록 |
| --- | --- | --- |
| 정면 설정 | 제자리 정지 후 ‘12시 설정’ | 약 1초 안정 구간에서 버튼 활성화. 흔들리는 상태에 강제 설정되지 않음 |
| 시계 방향 부호 | 초기 정면에서 3시/9시/6시 경로 각각 실행 | 오른쪽/왼쪽/뒤쪽이 실제 몸 기준과 일치. 외부 시계 표시와 비교 |
| 첫 걸음 | 출발 후 직진 20걸음, 종료 전 10초 정지 | 처음 두 주기를 함께 확인해 0→2로 갱신될 수 있음. 첫 보행 시각과 최초 표시 시각을 따로 기록. iOS 원본 수신 여부/지연, 관찰자 수동 계수 기록 |
| 속도·보폭 | 평소 보행/느린 보행/작은 보폭 각각 20걸음×3회 | 추정과 iOS 각각 실제 계수와의 차이. 둘 사이 차이를 정답으로 삼지 않음 |
| 무보행 오검출 | 30초 정지, 몸 회전만, 상체 흔들기, 음성/햅틱 각각 실행 | 추정 걸음 오검출 수 기록 |
| 자동 스팟 갱신 | 3시 10걸음 → 목표 방향으로 1.5초 정지 → 다음 스팟 3시 | 버튼 없이 도착 처리와 새 12시 설정. 두 번째는 멈춘 정면에서 다시 오른쪽. 목표 방향 12° 이내를 새 표본에서 0.6초 유지하면 ‘이동 중’ 전환과 걸음 안내 |
| 걸으며 다음 구간 시작 | 자동 도착 후 다음 방향으로 몸을 돌리고 자연스럽게 걸음 | 추가 정지 없이 방향을 맞춘 뒤 자동 출발. 확인된 0.6초 방향 정렬 중 감지한 걸음도 구간에 한 번만 반영하며 그 이전 회전 후보는 제외. 계속 ‘방향 맞추기’에 남아 세션 누적만 늘지 않음 |
| 자동 출발 전 센서 이상 | 다음 방향 정렬 도중 짧은 수신 공백 또는 잘못된 자세 재현 | 새 유효 표본으로 0.6초 방향 정렬을 다시 확인. 타이머만 지나거나 잘못된 자세에서는 출발하지 않음 |
| 직진 다음 스팟 | 첫 스팟 완료 → 다음 스팟 12시 | 다음 스팟 방향·걸음 안내 뒤 자동 출발. 이전 구간의 걸음이 새 구간에 반영되지 않음 |
| 자동 출발 취소 | 다음 방향을 맞추기 전 일시정지 또는 방향 재설정 | 자동 출발 대기 해제. 명시적인 계속/출발 조작 전에는 이동을 시작하지 않음 |
| 중간 정지 | 목표 걸음 전에 2초 이상 멈춤 | 도착 처리·기준 갱신 없음. 남은 걸음을 유지 |
| 도착 대기 중 움직임 | 목표 후 1초 정지했다가 걷기·몸 회전·폰 흔들기 각각 수행 | 정지 시간이 초기화되고, 움직임이 끝난 뒤 새 1.5초 연속 정지가 필요 |
| 틀린 방향의 도착 대기 | 목표 걸음 도달 후 한 시각 이상 틀린 방향으로 2초 정지 | 자동 도착하지 않고 시계 방향 보정 안내. 목표 방향 12° 이내에서 새 1.5초 정지 후에만 도착 |
| 도착 대기 중 수신 끊김 | 목표 후 정지 도중 센서 표본 중단/지연을 재현 | 시간 경과만으로 도착하지 않음. 정상 표본 재수신 후 연속 정지를 새로 확인 |
| 마지막 스팟 | 마지막 목표 걸음 후 1.5초 정지 | 자동 완료 후 저장/폐기 선택. 완료 후 추가 스팟·기준 갱신 없음 |
| 아직 미도착 | 목표 걸음 알림 후 자동 도착 전에 ‘도착 취소’ | 도착 대기를 취소하고 남은 걸음을 확인. 기존 목표 방향으로 재개 |
| 이동 중 방향 재설정 | 구간을 일부 걸은 뒤 상단 ‘방향 재설정’, 원하는 정면에서 1초 정지 | 걸음/목표 유지. 현재 정면이 이동 목표인 12시. 자동 보행 재개 없이 ‘계속 걷기’ 버튼 대기 |
| 출발 전 방향 재설정 | 3시 경로에서 출발 전 ‘방향 재설정’, 새 정면에서 1초 정지 | 새 정면의 3시가 목표. 12시 직진으로 바뀌지 않음 |
| 재설정 도중 움직임 | 재설정 후 1초가 되기 전에 걷기·회전·흔들림·수신 끊김 | 유지 시간이 초기화됨. 오래된 표본이나 시간 경과만으로 완료하지 않음 |
| 모든 단계에서 재설정 | 최초 설정·방향 맞춤·이동·도착 대기·오류 일시정지 각각 | 상단 버튼 사용 가능. 재설정 중 중복 시작되지 않음. 목표 달성 상태는 재설정 후 1.5초 도착 대기를 새로 시작 |
| 출발 직후 보정 | 출발 후 바로 한 시각(한 칸) 방향 이탈 | 이탈 1초 뒤 현재 몸 기준 시계 방향 음성. 출발 안내 후 5초를 기다리지 않음. 가벼운 보정으로 센서가 중지되지 않음 |
| 보정 반복·복귀 | 한 시각 이탈을 유지한 뒤 목표 방향으로 복귀 | 3초 간격 반복, 복귀하면 ‘방향 맞음.’ 한 번. 음성/VoiceOver/햅틱 각각 확인 |
| 다음 방향 대기 | 자동 도착 후 다음 목표 방향으로 돌지 않고 기다림 | 시계 방향 안내 반복. 방향을 맞추기 전에는 자동 보행·구간 걸음 증가 없음 |
| 큰 이탈/폰 탈착 | 몸 크게 돌리거나 폰을 눕힘 | 정지 안내. 큰 이탈에서는 유효한 센서로 방향 보정을 계속하며 자동 보행 재개 없음. 잘못된 자세는 정면으로 오인하지 않음. 임의로 새 12시를 설정하지 않음 |
| 일시정지 | 멈춤 후 몇 걸음 입력/보행 | 구간 수는 고정, 세션 누적은 계속. 위치/남은 걸음 확인 뒤 재개 |
| 앱 전환/잠금 | 앱 나갔다 돌아와 ‘방향 재설정’ | 이전 좌표계로 재개 불가. 이전 스팟 귀환을 강제하지 않고 현재 정면 재설정. 구간 걸음/목표 유지 |
| 출력 | 음성, VoiceOver, 햅틱 각각. ‘다시 안내’를 연속 사용 | ‘3시. 10걸음.’처럼 짧은 안내, 도 단위 음성 없음. 정지/다시 안내가 중복으로 차단되지 않음. 회전 2회/정지 길게. 진동의 걸음 오검출 여부 기록 |
| 결과 선택 | 종료 후 저장 및 폐기 각각, 재실행 | 저장은 기록 탭에 유지. 폐기는 복구 기록도 남지 않음 |
| 대시보드 | 방향/걸음/움직임 전환, 스팟/시간 변경, 시점 선택 | 시계 축, 두 센서 출처, 기준 갱신 표시와 원본 JSON 비교 |

자동 도착은 휴대폰의 추정 걸음과 정지 상태에 따른 판정입니다. 지도상의 실제 도착, 장애물, 경로 밖 위치를 확인하지 않습니다. 목표 걸음 추정이 틀리면 잘못된 위치에서 도착 처리될 수 있으므로 관찰자가 실제 위치를 함께 기록합니다.

방향 오차는 바닥에 표시한 실제 방향과 비교하고, 걸음은 관찰자가 셉니다. 시작/회전/정지/자동 도착/방향 재설정 각 시각과 기기·iOS 버전, 착용 상태를 함께 남깁니다. CSV/JSON을 내보내어 오검출·누락·수신 지연을 분석합니다. 실제 보행 성능 기준과 통과 여부는 이 측정 후 정합니다. 아직 통과한 것으로 간주하지 않습니다.
