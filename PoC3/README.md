# PoC3 · 몸 방향 + 무대 이동 안내

운영자 기기가 무대를 스캔하고 P 한 명의 위치를 추적한다. P는 별도 iPhone을 배 앞에 세로로 착용한다. 착용 폰의 몸 방향과 운영자 기기의 P·D 좌표를 결합해 **선택한 착용 폰 스피커 또는 에어팟에서 한국어 회전·전진·도착 안내**를 출력한다.

[구현 전 계획](../docs/poc3-implementation-plan.md)

## 열기와 설치

1. `PoC3.xcodeproj`를 Xcode에서 열고 `PoC3` 공유 스킴을 선택한다.
2. Signing & Capabilities에서 자신의 Team을 선택한다. Bundle ID 기본값은 `ggbcom.Jace.PoC3`이다.
3. iOS/iPadOS **26.2 이상**인 두 기기에 설치한다. 운영자 기기는 ARKit의 sceneDepth + personSegmentation을 지원하는 LiDAR iPhone/iPad, 착용 기기는 Core Motion을 지원하는 iPhone이 필요하다.
4. Wi-Fi와 Bluetooth를 켜고 로컬 네트워크 접근을 허용한다. 운영자 기기는 카메라 접근도 허용한다.

AirPods, 인터넷 서버, 계정 로그인은 필요하지 않다. 같은 앱에서 운영자/착용자 역할을 선택한다. 영상은 운영자 기기에서만 처리하며 전송하지 않는다. 지도·P 위치·몸 상대각·목표·제어 상태만 로컬로 전달한다. 이 버전은 세션/경로를 파일로 저장하지 않는다.

## 현장 실행 순서

1. **착용 폰:** `착용자 P`를 열고 6자리 연결 코드를 운영자에게 알려준다.
2. **운영자:** `운영자`에서 코드를 입력하고 표시된 착용 폰에 연결한다. 15초 내 실패하면 코드와 권한을 확인하고 재시도한다.
3. **착용 폰:** `스피커 / 에어팟`을 선택하고 `음성 출력 준비 · 소리 확인`을 눌러 준비 음성을 확인한다. 에어팟은 착용 폰에 연결한 다음 출력 기기 선택 버튼에서 선택한다. 미디어 음량을 조절한다.
4. **운영자:** `무대 스캔하고 P 추적하기` → 바닥 확정 → 원점 지정 → 카메라를 객석으로 향해 무대 앞쪽 설정 → 경계점 추가 → 경계 닫기.
5. 스캔을 닫지 않고 같은 기기로 **P 한 명**을 계속 촬영한다. `이 사람을 P로 선택` 후 P를 실제 시작 위치에 배치하고 `현재 P 위치를 시작점 S로`를 누른다.
6. 평면도를 터치하거나 `D 좌표로 지정`에 미터 좌표를 입력해 목적지를 정한다. S→D가 경계에 닿거나 밖으로 나가면 거부한다.
7. P의 몸을 **객석 방향**으로 정렬한다. 착용 폰 화면은 몸 바깥쪽을 향한다. 폰이 밴드에서 돌아가지 않게 고정한다.
8. P가 정면을 유지한 동안 운영자가 `P 객석 정렬 완료 · 정면 보정 요청`을 누른다. 착용 폰의 보정 음성과 운영자 화면의 `정면 보정 완료`를 확인한다.
9. 운영자가 `안내 시작`을 누른다. 시작 시 P는 저장된 S에서 0.5m 이내여야 한다.
10. D의 0.3m 이내에 들어오면 먼저 멈추라고 안내한다. 유효한 위치가 0.6초 유지되면 도착을 확정한다. 완료된 실행은 자동 재개되지 않는다. 다음 이동은 S·D를 다시 지정한다.

방향 보정은 센서와 무대 좌표의 수동 정합이다. 스캔 때 기기가 바라본 방향을 착용 폰이 자동으로 아는 것은 아니다. **P가 실제로 객석을 향해야** 두 기준이 일치한다.

## 음성 규칙

- 목표가 몸 정면 ±12°: “앞으로 2.1미터”처럼 남은 직선 거리를 말한다.
- 그 외: “왼쪽으로 45도 돌아주세요”처럼 15° 단위로 반올림해 안내한다.
- 회전은 제자리에서 하고, 정렬된 후 전진한다. 위치는 걸음 추정이 아니라 운영자 카메라가 계속 갱신한다.
- 방향 종류가 달라지면 이전 발화를 취소한다. 같은 종류는 최소 3초 간격으로 반복하며 발화를 쌓지 않는다.
- 착용자 `현재 몸 방향 듣기`는 이동 중이 아닐 때 정면 기준 상대각을 읽는다.
- 운영자/착용자 양쪽에 중지 버튼이 있다. 착용자 화면의 VoiceOver magic tap도 즉시 중지한다.
- 스피커 준비는 `playAndRecord` + speaker override를 사용한다. 녹음은 하지 않는다. 에어팟은 `playback` 세션으로 시스템이 선택한 Bluetooth 출력에 재생한다. 선택한 출력 종류와 기기 식별자, 한국어 음성, 음량을 확인하고 출력 변경이나 오디오 중단 시 안내를 중지한다.

## 좌표와 연결 계약

- 기존 무대 좌표 유지: +X 무대 오른쪽, +Y 뒤쪽, 객석은 (0,-1).
- 객석을 보는 P의 오른쪽은 **지도 -X**다. 화면의 오른쪽과 P 몸의 오른쪽을 혼동하면 안 된다.
- Core Motion `.xArbitraryZVertical`, 30Hz. `rotationMatrix`의 세 번째 행으로 화면 +Z의 수평 방향을 구한다. 수평 투영이 너무 작은 자세는 방향을 무효화한다.
- `MultipeerConnectivity`, 암호화 필수, 한 쌍만 연결. 착용 폰이 10Hz 요청을 보내고 운영자가 해당 요청 ID에 현재 상태를 응답한다.
- 서로 다른 기기의 uptime을 빼지 않는다. 착용 폰의 요청 시각 + 0.5초 − 운영자 위치 샘플 나이로 만료 시각을 계산한다. 네트워크 왕복 시간도 이 0.5초 예산에 포함된다.
- 요청 ID·응답 순서·제어 revision·경로/보정/실행 UUID를 구분한다. 이미 중지/완료한 실행이나 오래된 제어 상태가 늦게 와도 안내를 다시 시작하지 않는다.
- 영상/위치 소실, 센서 만료, 연결 문제, 경계 이탈은 이동 안내를 정지한다. 단순 신호 복구만으로 재개하지 않으며 운영자가 `안내 시작`을 다시 눌러야 한다. 몸 방향이 무효화되었거나 착용자가 중지한 경우 새 정면 보정도 필요하다.
- 백그라운드 전환은 운영자 AR 세션을 무효화한다. 다시 스캔한다. 착용 폰은 소리 준비와 정면 보정을 다시 한다.

## 조작 예제

첫 화면의 `센서 없는 이동 예제`에서 가상 몸 회전, 20cm 전진, D 선택 및 음성 문구를 확인한다. 센서와 두 기기 통신을 사용하는 실측 결과가 아니다. Simulator에서는 내장 스피커 출력으로 인식되지 않아 소리 준비가 차단될 수 있다.

## 운영 화면·인식·음성 개선 · 2026-10-11

- 착용 폰과 가상 이동 예제에서 **각도 / 시계 방향** 음성 표현을 선택한다. 선택은 기기에 저장된다. 이동 안내는 현재 몸 정면을 12시로 보며 오른쪽 30°→1시, 오른쪽 120°→4시, 왼쪽 30°→11시, 뒤쪽→6시다. `현재 몸 방향 듣기`는 무대 정면이 12시인 별도 기준임을 문구로 명시한다.
- 운영자 화면 상단에서 **평면도 · 설정 / 카메라 · 안내**를 전환한다. 안내 시작 시 카메라 화면으로 전환한다. 카메라 화면에서도 정면 보정·안내 시작·즉시 중지가 가능하다.
- 스캔 완료 후 무대 내부에 민트색 반투명 바닥과 기본 0.25m 간격의 얇은 회색 점선 격자를 표시한다. 큰 무대에서는 선 수를 제한하기 위해 간격을 넓힌다. 오목한 경계의 바깥 영역에는 격자가 그려지지 않는다.
- S·D 설정 시 같은 AR 좌표에 바닥 링·기둥·S/D 글자와 S→D 선을 표시한다. 카메라 시야 밖의 D는 보이지 않는다. 추적이 비정상이면 오버레이를 숨긴다. AR 표시는 실측 마커와의 현장 정합 확인이 필요하다.
- 최초 P 관절 신뢰도는 0.45에서 0.30으로 낮췄고, 최초 깊이도 medium 이상을 허용한다. 사람 마스크·유효 샘플 수·깊이 분산 검사는 유지한다. root/neck 외에 어깨 쌍·골반 쌍도 초기 위치 후보로 사용하며 단일 관절 fallback은 P 지정 후에만 사용한다.
- **P 선택과 위치 측정을 분리:** 영상상 사람이 보이면 깊이가 없어도 P를 지정할 수 있다. 감지 버튼은 계속 표시하고 최근 영상 감지를 1초 유지해 깜빡임을 줄인다. 유효한 위치가 없으면 S 확정/안내는 허용하지 않으며 기존 위치 만료 0.5초를 유지한다.
- 운영자가 P 정면에 있을 필요는 없다. 동일 AR 세션 안에서 운영자가 이동할 수 있다. 옆/뒤 모습을 차단하는 조건은 없지만, 몸통 관절·사람 마스크·깊이가 유효해야 위치가 나온다. 정면보다 인식이 불안정할 수 있으며 옆/뒤 실기기 정확도는 미검증이다.
- 깊이 샘플 허용 범위는 **0.2~6m**다. 카메라 Z-depth 필터 범위이므로 6m 반경 내 모든 사람의 인식을 보장하는 뜻은 아니다.
- 후속 변경으로 스피커 / 에어팟 출력 선택을 지원한다. 에어팟 모드는 Bluetooth 출력만 허용하며, 기기가 바뀌거나 연결 해제가 감지되면 안내를 중지한다.

후속 변경 검증: 계산·프로토콜·P 후보 유지·시계 방향·오목 무대 격자 검사 **79개 통과**. iPhone 및 Simulator 서명 제외 빌드 성공. 실제 카메라에서의 격자/D 정합, 완화된 인식 문턱의 오탐률, 옆/뒤 인식률은 현장 확인이 남아 있다.


### 스피커 / 에어팟 사용

착용자와 이동 예제 화면에서 출력 방식을 선택한다. 에어팟은 **운영자 기기가 아니라 착용 폰**에 연결한다. `출력 기기 선택`의 시스템 버튼 또는 제어 센터에서 에어팟을 선택하고 `음성 출력 준비 · 소리 확인`을 누른다. 현재 출력 기기 이름과 실제 준비 음성을 확인한 뒤 운영자가 안내를 시작한다. 출력 선택은 저장된다.

기기 이름은 사용자가 바꿀 수 있으므로 AirPods 브랜드를 판별하지 않고 Bluetooth 오디오 경로를 허용한다. 출력 변경·연결 해제 감지 시 발화를 취소하고 진행 중 안내를 중단한다. 다시 연결해도 자동 재개하지 않으며 소리 확인 후 운영자가 안내를 다시 시작해야 한다. 몸 방향은 계속 착용 폰에서 측정한다.

- [ ] 실제 AirPods 선택 및 준비 음성/방향 안내 청취
- [ ] 안내 중 에어팟 연결 해제·다른 Bluetooth 기기로 변경 시 중단 및 자동 재개 방지
- [ ] 스피커로 전환 후 내장 스피커 청취, 출력 선택 저장/복원

### 운영자 미니맵 회전

무대 스캔 완료 후 `평면도 · 설정`에서 `미니맵 180° 회전`을 누르면 객석이 위쪽으로 표시된다. `기본 방향으로 보기`로 되돌릴 수 있으며 선택은 저장된다. 경계·S/P/D·몸 방향 화살표가 함께 회전하고 글자는 똑바로 유지된다. 회전된 지도에서도 탭한 D는 실제 무대 좌표로 역변환된다.

검증: 미니맵 회전 및 탭 좌표 왕복 검사를 포함한 총 **92개 검사 통과**, iPhone 서명 제외 빌드 성공. 실제 기기 화면에서의 조작 확인은 남아 있다.

카메라 오버레이의 무대 테두리는 실선, S/D 고리·수직 표시선·S→D 경로는 점선으로 표시한다. iPhone 서명 제외 빌드 성공. 실제 무대 조명에서의 가독성은 현장 확인이 필요하다.

### 보폭으로 거리 듣기

착용자 또는 이동 예제 화면에서 거리 안내 단위를 `걸음 수`로 선택한다. 한쪽 발을 한 번 내딛는 길이를 `cm / m`로 입력하고 `적용`을 누른다. 초기값은 60cm이며 10~200cm(0.1~2m) 범위에서 설정할 수 있다. 화면의 `적용된 한 걸음` 값을 확인한다. 보폭과 거리 안내 단위는 앱을 다시 열어도 유지된다. 단위 변경 시 입력 칸에는 저장된 보폭을 환산해 표시한다. 잘못된 값은 저장하지 않는다.

60cm 보폭과 1.8m 남은 거리는 `앞으로 약 3걸음`이다. 남은 거리보다 더 걷도록 반올림하지 않고 정수 부분을 안내하며, 한 걸음 미만이면 `앞으로 작게 한 걸음`으로 표현한다. 안내는 카메라가 측정한 남은 거리로 갱신되고 실제 걸음을 세지는 않는다. 도착은 기존 0.3m 반경 및 연속 위치 확인 기준으로 판단하며 `도착했습니다. 멈추세요.`를 유지한다. 각도/시계 방향과 스피커/에어팟 설정을 함께 사용할 수 있다.

검증: 보폭 입력·환산·거리 문구·도착/회전 문구 검사를 포함해 **112개 통과**, iPhone 서명 제외 빌드 성공. 실제 보행과 음성 청취는 현장 확인이 남아 있다.
