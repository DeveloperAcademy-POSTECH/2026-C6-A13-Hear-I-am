# 세로 안내 UX 구현 계획

- 이슈: https://github.com/DeveloperAcademy-POSTECH/2026-C6-A13-Hear-I-am/issues/11
- 브랜치: `testflight/1-ux-refinement` (사용자 지정)
- 선행 와이어프레임: https://www.figma.com/design/GfvOEZoxjcen2Bv3zHh5YU?node-id=590-1149
- Figma 구성: 기본 흐름 G01–G12, 빈 목록·복원 실패·확인점 불일치·추적 중단·카메라 사용 불가·중간 종료 E01–E06. 편집 가능한 18개 세로 화면이며 각 화면 아래에 음성과 전환 조건을 표시했다.

## 범위

홈 → 실제 스캔한 무대 선택 → AR 공간 복원 → C 확인 → 허리띠 착용 → 출발 준비 → 순차 동선 안내 → 마지막 도착 → 홈.
공연 사전 도면, 기록 통계, 설정 세부 기능, 음성 명령, 이어폰 필수 단계는 제외한다.

## 구현 순서

1. 기존 RouteGuide에 명시적으로 허용한 세션에서만 버전 2의 무대 밖 출발·도착을 지원한다. 입장·퇴장은 현재 선분 주변에서만 허용하고, 내부 이동은 무대 안쪽과 경로 주변에 제한한다. 등록된 기물과 현재 위치/목표 선분도 검사한다.
2. 기존 ScanLabModel의 저장 공간 복원·C 검증·카메라 위치 추정을 재사용한다. 새 안내 화면의 TTS와 상태는 별도 Guidance 기능에서 관리해 기존 실험 화면과 중복 발화하지 않는다.
3. 한국어 AVSpeechSynthesizer를 사용한다. 설명 종료 후 착용 시간을 시작하고, 시작 문구 종료 후 이동 안내를 시작한다. 반복 방향 문구는 쌓지 않으며 중단 알림은 우선한다.
4. 세로 안내 선택/준비/이동 화면을 연결한다. 출발점 확인 전 임의 직선 유도는 하지 않는다. 추적·앱·오디오 중단 시 현재 목표를 보존하고 C와 착용을 다시 확인한 뒤 명시적으로 재개한다.
5. 마지막 도착 음성은 **“마지막 지점에 도착했습니다. 안내를 종료합니다.”**로 고정한다. 끝까지 재생 후 종료 버튼을 활성화하며 자동 추가 멘트는 없다. 재생 중 중단되면 종료 안내를 다시 들을 수 있다.

## 검증

- 코어: 버전 1 호환성, 버전 2 입장/퇴장, 내부/외부 경로 이탈, 기물 충돌, 도착 체류와 중복 방지, 중단 후 목표 보존, 음성 큐의 순서와 취소된 콜백 무시.
- 앱: iOS Simulator Debug 및 iPhone Release 빌드, 빈 목록/저장 목록 선택/미지원 기기/나가기 흐름 검증.
- 실기기: 공간 재인식·C 오차·허리띠 방향·스피커 TTS·카메라 추적·실측 위치·앱 전환/오디오 중단은 별도 현장 확인이 필요하다. 같은 높이 조건은 준비 시 저장된 바닥 좌표에 기반하며 실시간 단차 감지는 구현하지 않는다.
