## 자동 검증

- 기존 코어 36개 + 준비/사전 저장/고정/저장 왕복 8개: **44개 통과**.
- `PoC4` Debug generic iOS Simulator 빌드 성공 (서명 제외).
- `PoC4` Release generic iOS 빌드 성공 (서명 제외).
- 기존 안내 버전 1 회귀 테스트 유지. 버전 2 경로는 기존 안내에서 시작되지 않는다.

## 시뮬레이터에서 직접 확인

Xcode 27.0, iOS 27.0 iPhone 18 Pro. 테스트용 데이터는 제품에 포함하지 않는다.

- 큰 홈 카드·질문 문구·설정 버튼·기본 탭바 표시.
- 사전 편집 진입 시 가로 화면, 종료 시 세로 화면 복귀.
- 출발·내부 2점·도착을 입력하고 완료 시 마지막 점의 도착점 전환.
- 동선 위 장애물 추가 시 저장 차단, 기물 이동으로 충돌 해소 시 저장 재활성화.
- 이름 변경 → 저장 → 목록 표시 → 재편집. 미저장 변경을 버리면 기존 저장본 보존.
- 검증용 가상 메시 두 개로 최근 순서, 오래된 무대 고정, 중복 없는 목록 분리, 재실행 후 별 상태 보존.
- 가상 저장 메시와 무대/경로/확인점의 3D 미리보기 로드.
- LiDAR 미지원 환경에서 스캔 확정 버튼 비활성화와 기기 지원 안내.

가상 메시 검증은 실제 스캔·위치 정확도·공간 복원의 검증을 대신하지 않는다. AppIntents 미사용에 따른 메타데이터 추출 생략 경고만 확인했다.

## 실제 LiDAR iPhone에서 남은 확인

- [ ] 실제 공연장·백스테이지 스캔 후 mapped 상태와 메시 수집, 공간 확정.
- [ ] 가로 카메라 뷰의 십자선과 AR raycast 위치 일치, 네 모서리 순서·정면·높이 확인.
- [ ] 기물 둘레 및 경로의 실제 좌표와 줄자 비교; 낮은 조명/반사 바닥에서 인식 실패 안내.
- [ ] 무대 범위 수정 후 기존 경로·기물·확인점의 세계 위치 보존과 오류 재검사.
- [ ] 스캔 중 앱 백그라운드/카메라 중단 → 같은 공간에서 추적 재개.
- [ ] 지도 요청 지연/저장 장치 오류 후 입력 유지·재시도, 성공 후 재실행 및 3D 열기.
