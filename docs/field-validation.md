# 착용 검증 절차

이 문서는 실제 시험 결과가 아니라 수행할 검증 절차입니다. 앱의 계산 테스트와 시뮬레이터 빌드는 실제 착용 정확도나 진동 인지를 보장하지 않습니다.

## 시험 조건 기록

아이폰 모델 / iOS 버전 / 케이스 / 밴드 재질·조임 / 옷 두께 / 시험자 / 날짜를 기록합니다. 앱을 전면에 열어 화면을 켜고 배 앞쪽 허리에 세로 고정합니다. 화면은 바깥쪽입니다.

## 1. 신호 방식과 패턴 구분

설정에서 진동·음성·비프음을 하나씩 선택하고 정면·뒤쪽을 포함한 30° 간격의 12방향를 각각 미리 재생합니다. 화면을 보지 않고 어떤 신호인지 응답하도록 한 뒤 순서를 바꿔 반복합니다. 식별 성공 횟수, 혼동한 조합, 너무 약하거나 불편한 패턴을 기록합니다. 진동은 세기뿐 아니라 패턴을 바꿔 비교합니다. 음성은 좌우와 각도 발음을 확인하고, 비프음은 낮은 음/높은 음 및 1·2·3회를 구분하는지 확인합니다. 음성·비프음은 실제 공연장 소음 및 사용할 이어폰 조건에서도 반복합니다.

## 2. 각도 검증

바닥에 기준선과 정면·뒤쪽을 포함한 30° 간격의 12방향 선을 표시합니다. 기준선에서 리셋하고 각 선으로 10회씩 회전해 화면 각도, 신호 발생, 누락·중복을 기록합니다. 초기 오차 목표는 ±5°이며 실측 결과로 판단합니다. 몸을 약간 숙이거나 좌우로 기울여 방향값이 달라지는 정도도 기록합니다.

경계에서 작게 흔들기, 천천히 통과하기, 30°와 60°를 빠르게 연속 통과하기, ±180°를 넘기기, 한 바퀴 돌기, 다시 되돌아가기 모두 확인합니다. 빠른 통과에서는 가장 최근 도달한 신호가 우선하므로 지난 신호가 길게 이어지면 실패입니다.

## 3. 공연 동작 한 사이클

1. 보조자가 몸의 정면을 정렬합니다.
2. 화면 버튼으로 0°를 설정합니다.
3. 앞으로 7걸음 이동합니다.
4. 왼쪽 30°(11시 방향)로 회전해 신호를 확인합니다.
5. 로그에 보관할 값들을 확인한 뒤 다시 리셋합니다.
6. 새 사이클이 0°·0걸음·(0,0)에서 시작하고 이전 값은 로그에 남는지 확인합니다.

걸음 수는 수동 계수와 비교합니다. 이동 거리는 줄자로 확인한 거리와 비교하되 추정 좌표 결과를 방향 검증과 분리해 기록합니다. 걷고 즉시 리셋하거나 리셋을 연속해서 눌러도 이전 사이클 걸음이 새 사이클에 들어오면 안 됩니다.

## 4. 화면·설정·중단

- 신호 방식을 바꾸고 앱 재실행 후 유지되는지, 이전 진동 패턴이 보존되는지 확인합니다.
- 미디어 음량 0/보통, 무음 모드, 스피커/이어폰 출력, 이어폰 연결 해제, 시스템 오디오 중단을 확인합니다.
- 음성/비프음 체험과 리셋에서 진동이 동시에 나오지 않는지 확인합니다.
- 각도별 신호 사용 여부와 패턴·세기·선명도를 변경하고 앱 재실행 후 유지되는지 확인합니다.
- 해당 신호 재생 중 전체 화면이 단색이고 방향과 각도가 큰 글씨로 표시되는지 확인합니다.
- 신호 종료·취소·새 신호·리셋·앱 중단 시 오래된 화면이 남지 않는지 확인합니다.
- 동작 권한 거부, 화면 잠금, 앱 전환, 다시 실행을 확인합니다.
- 백그라운드 전환 이후 앱이 이전 기준을 유효한 것처럼 사용하지 않고 재리셋을 요구하는지 확인합니다.
- 최초 권한 팝업에서 허용한 뒤 걸음 사이클이 유지되는지 확인합니다.
- 방향 기준이 무효화되어도 걸음 집계가 이어지는지 확인합니다. [리셋·걸음 상세 검증](reset-and-steps.md)을 함께 수행합니다.
- VoiceOver로 리셋·측정 중지·설정·로그를 사용할 수 있는지 확인합니다.

## 12방향 확장 확인

1. 현재 몸 정면을 12시로 설정하고 오른쪽으로 30°씩 돌아 1시~11시~12시를 확인합니다. 반대 방향으로도 반복합니다. 기준이 회전 중 자동으로 바뀌면 실패입니다.
2. 12시 근처와 6시 근처에서 작은 흔들림을 반복합니다. 중복 신호가 없어야 하며, 6° 이상 벗어난 뒤 돌아오면 다시 알려야 합니다. 리셋 직후에는 리셋 신호만 한 번 나와야 합니다.
3. 화면 각도/시계 표시와 음성 각도/시계 표현을 교차 선택합니다. 화면 330°와 “11시 방향”, 화면 11시와 “왼쪽 30도”를 확인합니다. 180°는 뒤쪽/6시입니다.
4. VoiceOver를 켜고 설정 선택·방향별 체험·리셋을 실행합니다. 기존 두 손가락 두 번 탭 리셋과 화면 읽기가 유지되는지, 앱 음성과 안내가 겹치지 않는지 청취합니다. 빠른 회전 시 오래된 음성이 뒤늦게 나오지 않아야 합니다.
5. 길이 조합 4종과 속도 변화 4종을 각각 무작위 순서로 체험합니다. 길이/순서와 간격의 차이를 구별하는지 기록합니다. 허리 착용·케이스·보행 조건을 함께 기록하고, 같은 패턴을 여러 방향에 배정한 경우 방향 식별 결과로 집계하지 않습니다.
6. 앱을 재실행해 표시·음성 표현·방향별 패턴·세기·선명도·사용 여부가 유지되는지 확인합니다. 이전 설치본의 ±45° 사용자 설정은 ±60°로 옮겨지고 기존 45° 로그는 유지되어야 합니다.

이 절차는 작성 완료이며 실기기 수행 완료를 뜻하지 않습니다.
