## 현재 적용: 실제 무대 안내에 3·2·1 비프 연결 (2026-10-20)

사용자가 몸·고개 시험에서 선택한 3·2·1을 실제 정상 이동과 경로 복귀에 연결했다. 구현 커밋은 `3e0978b`다. 실제 안내는 허리 iPhone의 몸 방향으로 판단하며, 고개 센서는 비교 시험에서 사용한다. 정렬 띠링 재생 시작 후 0.65초를 기다려 남은 거리·기물 음성이 정렬음을 자르지 않게 했다. 코어 XCTest 204개와 iOS 빌드가 통과했다.

## 비교 실험 추가: 왼쪽 높은 음 · 오른쪽 낮은 음 · 3·2·1 (2026-10-20)

**소리 테스트 → ④ 몸 vs 고개로 방향 찾기 → 비교 실험 · 3·2·1 비프**에서 ‘몸으로 찾기 · 3·2·1’ 또는 ‘고개로 찾기 · 3·2·1’을 누른다. 기존 지속음 버튼도 같은 화면에 남아 있어 ‘그만’ 후 바꿔 들을 수 있다. 두 방식 모두 시작 순간의 방향을 목표로 고정한다. 이 실험은 방향 정렬만 시험하며 실제 경로 복귀 완료를 판정하지 않는다.

| 목표를 향해 돌아야 하는 방향 / 남은 각도 | 소리 |
| --- | --- |
| 왼쪽 | 1,200Hz 높은 비프 |
| 오른쪽 | 600Hz 낮은 비프 |
| 90° 초과 | 3번 |
| 30° 초과~90° | 2번 |
| 10° 초과~30° | 1번 |
| ±10° 안에서 0.35초 유지 | 띠링 한 번, 이후 무음 |
| 정렬 후 16° 이상 벗어남 | 비프 재개, 다시 정렬하면 띠링 |

- 비프 하나는 0.12초, 묶음 안 무음은 0.12초다. 묶음 시작 간격은 1.2초로 고정한다. 3번 묶음은 0.6초, 나머지 0.6초는 무음이다. 음높이와 반복 속도는 각도에 따라 바뀌지 않고 횟수만 바뀐다.
- 같은 쪽에서 각도 구간만 바뀌면 현재 묶음을 끝내고 다음 시작 시점의 최신 횟수를 재생한다. 빠르게 돌았다고 지나간 묶음을 몰아 읽지 않는다. 회전 지시가 반대로 바뀌거나 정렬 범위에 들어오면 이전 묶음을 즉시 중단한다.
- 정렬 범위에서는 0.35초를 확인하는 동안도 비프를 멈춘다. 10~16° 구간은 정렬 전에는 1번, 정렬 후에는 무음으로 유지해 경계 흔들림을 줄인다. 뒤쪽 180° 경계 ±8°에서는 이전 회전 지시를 유지한다.
- ‘비프 슬라이더’로 센서 없이 ±150°, ±60°, ±20°, 0°를 비교할 수 있다. 음성·경고·0.5초 이상 센서 유실 때 비프와 정렬음을 중단한다. 출력 변경·화면 비활성화·‘그만’도 시험을 종료한다.
- 기존 지속음은 그대로 비교한다: 왼쪽 80→60Hz, 오른쪽 40→60Hz, 정렬 후 작은 60Hz 유지. 이번 새 비프 방식은 별도 버튼이다. 이후 사용자 선택에 따라 실제 무대 안내에도 3·2·1을 적용했다. 거리·기물·단상 규칙은 유지한다.

### 기기 비교 순서

1. 같은 방향을 바라보고 몸 시험을 시작한다. 시작 안내 후 처음 정렬을 확인하는 띠링이 한 번 나고 조용해지는지 확인한다.
2. 몸을 오른쪽으로 약 150° 돌렸다가 목표로 되돌아온다. 왼쪽으로 돌아야 하므로 **높은 3번 → 높은 2번 → 높은 1번 → 띠링 → 무음** 순서다.
3. 반대로 왼쪽으로 돌아갔다가 되돌아온다. **낮은 3번 → 낮은 2번 → 낮은 1번 → 띠링 → 무음**인지 확인한다.
4. 정렬 후 서 있어도 띠링이 반복되지 않고, 16° 이상 벗어나면 비프가 재개되는지 확인한다. ‘그만’ 후 같은 출발 방향에서 지속음으로 비교한다.
5. 고개 시험은 고개를 정면으로 두고 시작한다. 몸을 고정하고 편한 범위에서 좌우 음높이·2번·1번·정렬을 확인한다. 큰 각도와 3번은 슬라이더로도 비교한다. 고개 센서 값이 들어오는 AirPods가 필요하다.
6. 음성·장애물 경고 재생, 화면 이동, 출력 기기 변경 시 이전 비프가 남지 않는지 확인한다.

코어 XCTest **203개 통과, 실패 0**(기존 194개 + 횟수·좌우·정렬·중단·파형 9개). iOS 서명 제외 빌드 성공. 실제 iPhone·한쪽 AirPod 청취 평가는 아직 하지 않았다.

## 현재 실험: 작은 지속음으로 60Hz에 맞추기 (2026-10-20 정정)

**④ 몸 vs 고개로 방향 찾기 → 새 실험 · 작은 지속음 40~80Hz**에서 시험한다. 반복되는 짧은 삐비빅으로 해석한 것이 잘못이었다. 현재 시험은 작은 한 음을 끊김 없이 유지하고, 목표 각도에 따라 음높이만 바꾼다.

- 기본은 **부드럽게**다. 왼쪽으로 돌아야 할 때는 각도가 줄수록 **80→70→60Hz**, 오른쪽으로 돌아야 할 때는 **40→50→60Hz**로 이동한다. 중간 주파수도 연속적으로 지난다. 예: 왼쪽 180°=80Hz, 135°=75Hz, 90°=70Hz, 45°=65Hz, 정렬=60Hz.
- 기존 10Hz 요청을 비교할 수 있도록 **10Hz 간격** 옵션도 둔다. 이 옵션도 음을 끊거나 반복 재생하지 않고, 40·50·60·70·80Hz 목표 사이를 부드럽게 연결한다. 기본 선택은 연속 변화다.
- ‘높은 소리 섞음’의 기본 주파수+4배 배음(0.35 비율) 음색을 사용하되, 기존 12Hz 진폭 펄스를 제거했다. 같은 각도에서는 일정한 크기의 한 음이 계속 난다. 0.25초 음원이나 0.9초 반복 타이머로 소리를 재시작하지 않는다.
- 실시간 오디오 스트림 한 개가 위상을 유지한다. 센서 갱신·오디오 버퍼 경계에서 음의 위상이나 음량 포락선을 처음부터 시작하지 않는다. 음높이는 약 80ms, 음량은 약 15ms에 걸쳐 부드럽게 바꾼다.
- 지속음 기본 크기는 12%이며 화면에서 2~30%로 조절할 수 있다. 기기 전체 음량은 별도다.
- ±10°에서 0.35초 유지하면 **띠링 한 번**을 겹쳐 들려준다. 작은 60Hz 소리는 그동안과 이후에도 유지된다. 정렬 반경을 16° 이상 벗어난 뒤 다시 맞춰야 띠링이 다시 난다.
- 몸·고개 시험은 시작 순간의 방향을 고정 목표로 삼는다. 기준음 60Hz는 고정된 작은 연속음이다. 슬라이더도 같은 오디오 스트림으로 각도를 시험한다. 이전 휘익·진동·부르르 버튼은 비교임을 명확히 표시했다.
- 음성·경고 중에는 지속음을 멈춘다. 센서 또는 주파수 명령이 0.5초 넘게 갱신되지 않으면 무음으로 전환한다. 출력 변경·오디오 중단·화면 비활성화·종료·‘그만’에서도 멈춘다.
- 지속음은 비교 시험으로 남긴다. 이후 실제 무대 안내에는 사용자가 선택한 3·2·1 비프를 적용했다.
- 장애물 경고는 기존 거리별 비프, 좌우 기물 이름은 기존 음성 안내다.
- 코어 테스트 **194개 통과**(기존 179개 + 지속음 15개), iOS 서명 제외 빌드 성공. 파형의 3초 연속 RMS로 반복 펄스·무음 구간이 없음을 검증했고, 버퍼 위상 연속성과 정렬 후 60Hz 유지도 확인했다. 실제 iPhone·AirPods 청취 평가는 남아 있다.

## 실제 무대 안내 규칙

배꼽 방향은 허리 앞에 고정한 iPhone의 수평 방향으로 측정한다. 고개 방향이나 좌우 스테레오 차이를 사용하지 않는다.

| 상황 | 출력 |
| --- | --- |
| 왼쪽 회전 필요 | 1,200Hz 높은 비프 |
| 오른쪽 회전 필요 | 600Hz 낮은 비프 |
| 오차 90° 초과 / 30° 초과~90° / 10° 초과~30° | 각각 3번 / 2번 / 1번 |
| ±10° 안에 0.35초 연속 유지 | 띠링 한 번 후 방향음 무음 |
| 정렬 후 16° 이상 이탈 | 방향 비프 재개 |
| 경유지 도착 | 기존 띵, 다음 목표로 정렬 상태 초기화 |

방향 정렬 띠링과 경유지 도착 띵은 현재 같은 벨 음색을 사용한다. 정렬 띠링은 목표를 바라본다는 뜻이며 경로 복귀 완료나 지점 도착을 판정하는 신호가 아니다. 경유지 도착은 별도 거리·머무름 판정으로 처리한다. 마지막 지점은 기존 완료 음성으로 안내한다.

비프 길이는 0.12초, 묶음 안 무음은 0.12초, 묶음 시작 간격은 1.2초다. 같은 쪽의 각도 구간 변경은 다음 묶음부터 최신 횟수로 반영한다. 좌우 회전 지시가 바뀌거나 정렬 범위에 들어오면 이전 묶음을 즉시 멈춘다. 뒤쪽 180° 경계 ±8°에서는 이전 회전 지시를 유지한다. 목표를 빠르게 스쳐 지나가기만 하면 띠링이 나지 않는다.

## 실제 안내와 복귀

- 정상 안내는 현재 위치에서 다음 경유지를 향한 상대각을 사용한다.
- 경로 이탈 때는 기존 복귀 규칙으로 현재 구간의 가장 가까운 점을 향한다. 구간 위에서는 가까운 등록 기물 표면에서 멀어지는 방향을 사용한다. 복귀 방향을 정할 수 없으면 방향음도 내지 않는다.
- 기존 복귀 완료 조건(유효 위치 1초 유지)을 만족한 후 정상 안내로 돌아가며 정렬 판정을 초기화한다.
- 음성·장애물 경고 중에는 방향음과 정렬음을 멈춘다. 장애물 근접 시 멈춤과 회전 방향을 말하며 경고가 끝나야 방향 비프가 재개된다.
- 단상 진입은 “단상 접근”, 좁은 단상 통과는 “단상 접근. 바로 내려감.”으로 알린다. 계단·하강 안내와 장애물 경고는 유지한다.
- 도착 반경 안에서는 불안정한 목표 각도 대신 도착 판정을 기다린다. 경유지 도착 후 0.7초는 방향음을 쉬고 다음 목표를 안내한다.
- 일시정지·종료·음성 시작·오디오 오류·추적 유실 때 방향음을 정지한다. 위치 자료가 0.5초 넘게 갱신되지 않으면 안내를 중단한다.

## 남은 거리 · 좌우 기물 안내

- 거리 기준은 허리 iPhone의 현재 평면 위치에서 다음 경유지까지의 거리다. 단상 모서리나 발끝 기준으로 바꾸지 않는다.
- 방향 정렬 띠링을 끝까지 듣도록 재생 시작 후 0.65초 기다린 뒤 최신 거리를 읽는다: 1.5 → “일점오”, 3.2 → “삼점이”, 0.7 → “영점칠”. 정수는 “이”처럼 읽고 소수점 한 자리로 반올림한다. 이는 발음 형식이며 10cm 정확도 보장은 아니다.
- 마지막으로 읽은 실제 거리보다 1m 감소하면 읽는다. 현재 남은 거리가 2m 이하면 감소 기준은 0.5m다. 예: 3.2 → 2.2 → 1.7 → 1.2. 정지·재정렬·같은 구간 재개에서는 같은 값을 반복하지 않는다. 목표가 바뀌면 초기화한다.
- 거리나 기물 발화 시작 간격은 최소 1.5초다. 밀린 숫자·기물 안내는 저장하지 않고, 말할 수 있는 시점에 최신 위치로 다시 계산한다.
- 정렬 후 첫 거리가 우선이다. 그 뒤에는 지나가는 순간을 놓치지 않도록 현재 옆에 있는 기물 안내를 정기 거리 안내보다 우선하고, 다음 거리 안내는 최신 값으로 읽는다.
- 기물 경계에서 1.5m 이내이고 배꼽 기준 좌우 90°±20°에 있는 등록 기물의 이름을 읽는다. 양쪽이 있으면 “오른쪽 책장, 왼쪽 책상”으로 묶고, 같은 쪽은 가장 가까운 하나만 선택한다. 경계까지 0.35m 이내인 기물은 중립 위치 안내에서 제외하고 기존 위험 판정에 맡긴다.
- 최근 0.8초의 12cm 이상 이동, 전방 진행, 최근 이동 지속 여부와 방향 안정성을 확인한다. 정지·제자리 회전·후진 중에는 기물 안내를 시작하지 않는다. 긴 기물은 중심점이 아닌 가장 가까운 경계를 기준으로 한다.
- 한 번 안내한 기물은 계속 옆에 있거나 경유지만 바뀌어도 반복하지 않는다. 2m보다 멀리 떨어진 뒤 다시 지나갈 때 재안내할 수 있다.
- 방향이 16° 이상 틀어지거나 경고가 발생하면 거리·기물 음성을 중단한다. 기물이 더 이상 같은 옆에 없으면 진행 중인 해당 설명도 중단한다. 단상·계단 음성과 도착·정지·추적 유실이 이 안내보다 우선한다.
- 기본 도착 조건 **0.35m 안에서 0.8초 유지** 및 저장된 개별 설정은 변경하지 않는다. 도착 반경에 들어가면 거리·기물 안내를 멈추고 기존 도착 판정을 기다린다. 보폭 입력이나 걸음 수 환산, ‘점삼·점일’ 정밀 접근은 추가하지 않는다.

## 확인 방법

1. 에어팟 한쪽을 착용하고 ‘폰 스피커로 듣기’를 끈다. ④의 몸 3·2·1에서 높은 왼쪽·낮은 오른쪽과 정렬 후 무음을 확인한다.
2. 저장한 스캔 무대를 복원하고 확인점·출발 위치를 확인한 뒤, iPhone을 허리 앞쪽에 고정해 실제 안내를 시작한다.
