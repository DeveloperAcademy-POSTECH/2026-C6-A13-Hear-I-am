## 최신 develop과 결합한 부분

- 사용자 지시에 따라 충돌하는 동작은 **develop을 항상 우선**한다. 신호·음성·이동 안내와 소리 테스트 구현은 분기 기준 develop을 유지한다.

## 이번에 구현한 범위

저장 공간을 열면 `스캔 보기`가 기본으로 나온다. 기존의 어두운 배경·회색 원본 메시·청록색 무대 경계·빨간 기물 영역·노란 확인점·주황색 인물 표시를 사용한다. 전체 시점은 무대 경계 밖의 스캔 영역까지 포함하며 표면 선을 켤 수 있다. `정리해서 보기`는 갈색 원목 바닥과 밝은 웜그레이 기물을 보여준다. 무대 밖에서 스캔된 바닥과 주변 표면도 이어서 표시한다. 두 보기 모두 전체 스캔 범위에 카메라를 맞추며 기본 진입은 기존 스캔 보기다.

- 전체와 동선 위에서, 두 가지 빠른 카메라 시점. 핀치로 직접 확대할 수 있다.
- 시점을 바꿀 때 이전 카메라의 회전 축과 관성을 이어받지 않으며, 전체→위→전체 왕복 후 같은 전체 구도로 돌아온다.
- 수동 회전은 바닥을 내려다보는 15°부터 89.5°까지 허용한다. 동선 위 시점은 직교 투영과 89°를 사용해, 정확히 수직인 지점에서 반복 드래그하면 카메라가 뒤집히는 SceneKit 동작을 피한다. 좌우 회전과 두 손가락 이동·핀치 확대는 유지한다. 이 제한은 회전 각도에 적용한다.
- 3D 화면 오른쪽 위 `시점 초기화`를 누르면 이동·회전·확대와 관성을 초기화하고 전체 구도로 돌아온다. 정리/스캔 표시와 선택한 기물·사진은 유지한다.
- 번호와 진행 방향이 있는 동선. 지점을 선택하면 인물 모형이 해당 위치와 다음 방향을 표시한다. 마지막 점에서는 직전 구간 방향을 사용한다.
- 기물 선택 시 카메라를 이동시키지 않고 등록된 바닥 영역과 상세 정보를 표시. 화면 안 모형 터치와 하단 목록 모두 지원한다.
- 의자·테이블·보면대·마이크·스피커·바닥 모니터의 임시 모형. 기본 입체·의자 영역·계단은 등록된 다각형을 사용한다.
- 기물 등록 단계에서 표시 모형과 객석 기준 방향을 선택한다. 기존 통행 정책과 충돌 영역은 별도로 유지한다.
- 인물은 등록된 동선을 설명하는 표시다. 실제 사람 감지나 녹화된 이동 위치가 아니다.

## 코드로 구현한 인물·표식 디자인 (2026-10-21)

승인된 전체/위 시점 시안을 정리 화면의 표시 전용 SceneKit 도형으로 구현했다. 외부 3D 모델이나 새 이미지 파일은 필요하지 않다.

- 인물: 아이보리 상의·블루그레이 바지·신발과 단순한 머리 형태. 약 1.7m의 정적인 도형 조합이며 선택 지점의 저장 높이와 진행 방향을 따른다.
- 출발: 파란색 원판과 입체 흰 화살표. 첫 구간 방향을 가리킨다.
- 도착: 코랄색 핀·아이보리 체크·바닥 링. 핀 부분만 카메라를 향하고 바닥 링은 저장 좌표에 고정되어 위 시점에서도 읽을 수 있다.
- 중간 지점: 짙은 초록색 원판(`#1F7354`)에 밝은 번호. 선택한 지점에는 얇은 파란 링을 표시하고, 인물과 표식을 눌러 같은 지점을 선택할 수 있다.
- 경로: 무광 검정에 가까운 차콜(`#1F1F1F`) 점선과 방향 화살표. 밝은 스캔 메시와 구분되도록 이전 아이보리 표시를 교체했다. 표식 아래로 선이 파고들지 않게 양 끝을 줄이고 화살표 주변에 간격을 둔다. 짧은 구간은 원판만 표시한다. 저장된 높이 차이를 보간하며 기존 경로를 새로 계산하지 않는다.
- 무대 범위: 실제 등록된 사각형을 황토·브론즈색(`#C79440`) 선과 낮은 L자 모서리로 표시한다. 원목과의 대비를 보완하는 어두운 밑선과 3.2cm 선 너비를 사용한다. 청록색 채움이나 울타리를 만들지 않는다.
- 기물 범위: 선택한 기물의 실제 등록 다각형만 브론즈색 점선으로 표시한다. 빨간 원본 영역 표시와 노란 확인점은 스캔 보기에 남긴다. 위험 구역의 기존 경고 표시는 두 보기에서 유지한다.
- 사진: 정리 화면에서 연결 사진 카드는 접힌 상태로 시작한다. 촬영 위치 표시는 보기별 설정으로 분리하고 정리 화면에서는 기본으로 숨긴다. 사진 목록에서 직접 고르거나 토글을 켜면 위치를 볼 수 있다. 스캔 보기의 기존 기본값은 유지한다.
- 도형은 화면 구성 때 만들어 재사용한다. 인물·경계·점선의 정적인 도형은 합치고, 긴 구간도 구간당 최대 160개 점선으로 제한한다. 사용자 스캔 메시·저장 정보·실제 안내 판정은 바꾸지 않는다.
- 점선과 화살표는 기존 스캔 동선처럼 다른 표면에 가려져 끊기지 않도록 위에 그린다. 이 표시가 실제로 기물을 통과할 수 있다는 뜻은 아니며, 저장된 좌표·높이와 통행 판정은 그대로다.

### 나중에 준비하면 좋은 모델

1. **인물 한 종**: 현재 도형보다 자연스러운 실루엣·옷·손이 필요할 때 가장 우선이다. 현재 정적 다시보기에는 리깅이 필수는 아니다. 이후 재생에는 휴머노이드 골격과 대기·걷기 클립을 같은 모델에 제공한다. 앱이 기록 좌표를 적용하므로 제자리 걷기 클립을 기본으로 준비한다.
2. **실제 기물**: 의자, 테이블, 보면대, 마이크 스탠드, 스피커, 바닥 모니터를 필요 순서대로 교체할 수 있다. 외형을 바꿔도 통행 판정은 등록된 영역·높이를 사용한다.
3. **출발·도착·구역은 별도 모델 불필요**: 코드 도형으로 유지하면 색상·크기·방향을 쉽게 조절할 수 있다.

전달 형식은 SceneKit에서 확인할 USDZ 또는 SCN과 편집 가능한 원본을 권장한다. 단위 m, 위 +Y, 정면 +Z, 발/바닥 접촉 중심 원점을 사용한다. 인물 높이 약 1.7m, 기물은 실제 크기와 기준 방향을 함께 전달한다. 재질은 무광 색상과 거칠기 위주이며 첫 적용은 단순한 재질로 시작한다. 에셋 로딩과 리깅 애니메이션 연결은 아직 구현하지 않았다.

## 사진을 남기는 흐름

1. 무대 준비 중 추적이 정상일 때 `사진 남기기`를 누른다. 자동 연속 촬영은 하지 않는다.
2. 실행 중인 ARSession의 현재 프레임에서 이미지와 카메라 위치·방향·시간을 함께 가져온다. 별도 카메라 세션을 켜지 않는다.
3. 같은 위치에 ARAnchor를 추가한다. 최종 공간 지도의 앵커 좌표로 촬영 위치를 갱신해 메시와 같은 좌표계를 사용한다.
4. 메인 화면 작업과 분리해 화면 방향을 보정하고 JPEG와 썸네일을 만든다. 최대 긴 변 1600px, 썸네일 320px이며 공간당 40장까지다.
5. 준비 중에는 임시 파일로 보관한다. 사진 목록에서 등록된 기물이나 동선 지점을 연결하거나 연결을 해제하고 삭제할 수 있다.
6. 공간 저장 시 지도·메시·사진·촬영 정보를 하나의 묶음으로 저장한다. 중간 실패 시 완성되지 않은 저장 묶음은 제거하고 준비 중 사진은 재시도를 위해 유지한다.
7. 다시보기에서 연결된 기물·지점 선택 시 작은 사진 카드가 나타난다. 카드를 접거나 크게 볼 수 있고, 사진 목록에서 촬영 위치와 방향도 선택할 수 있다.

촬영은 저장 처리와 중복되지 않는다. 추적 중단·화면 종료·세션 교체 뒤에 늦게 돌아온 촬영 결과는 추가하지 않는다. 기물이나 지점을 삭제하거나 새 도면을 적용할 때 예전 사진의 연결을 해제해 새 대상에 잘못 붙지 않게 한다.

카메라 사용 설명에 현장 사진 촬영을 추가했다. 사진은 앱의 저장 공간에 보관하며 사진 보관함 접근 권한을 요청하거나 자동 업로드하지 않는다.

## 저장 및 호환

- `ScanManifest.photos`는 선택적 추가 필드다. 이전 manifest v1/v2에 필드가 없으면 빈 목록으로 읽는다.
- 사진마다 UUID, 촬영 시각, 프레임 시간, 열 우선 4×4 카메라 변환, 보정된 픽셀 크기, 파일 해시, 선택적 기물 ID/동선 인덱스를 보관한다.
- `photos/<UUID>.jpg`, `photos/<UUID>-thumb.jpg`를 공간 묶음 안에 둔다. 이름 변경은 그대로 보존하고 공간 삭제 시 함께 제거한다.
- 파일 크기와 해시를 검사하며 사진은 필요한 시점에만 읽는다. 사진 파일이 없거나 손상돼도 지도·메시 로딩을 막지 않고 해당 사진에 오류를 표시한다.
- `StageObstacle.appearance`가 없는 예전 자료는 기본 입체로 표시한다. 모르는 모형 값도 기본 입체로 읽는다.
- 측정하지 못한 높이는 표시용 기본값을 사용하며 상세 카드에 미측정임을 표시한다. 기본 높이를 실제 측정값으로 저장하지 않는다.
- 계단은 단 수를 추정하지 않고 영역과 높이만 표시한다. 준비 단계에서 지정한 올라감·내려감 변은 저장·안내에 유지되며 현재 모형에는 표시하지 않는다.

## 추후 모델을 교체할 때

`ReplayModelFactory`가 모형을 만들고, `ObjectAppearance`와 `ObjectPlacement`가 종류·방향·위치·크기를 제공한다. 실제 에셋을 불러오는 코드를 팩토리에 연결하면 배치·선택·사진 연결을 유지할 수 있다. 현재는 외부 에셋 로더를 추가하지 않았다.

- 단위: 미터, 위쪽: +Y, 바라보는 방향: +Z.
- 원점: 바닥에 닿는 부분의 중심. 모델 원본의 축·원점·실제 크기를 함께 전달한다.
- 텍스처는 은은한 색과 거칠기 위주로 시작한다. 복잡한 재질이나 고해상도 텍스처는 실제 기기에서 성능을 확인한 뒤 적용한다.
- 실제 모델 외형과 등록된 장애물 영역은 다를 수 있다. 안내 판정은 등록 영역을 사용한다.
- 사람이 움직이는 단계에서는 리깅된 모델과 걷기/대기 클립, 실제 기록의 위치·방향·시간 데이터가 추가로 필요하다.

## 나중에 할 것

사용자가 제공할 실제 3D 에셋과 기물별 텍스처 적용, 사진을 메시 표면에 투영하는 작업, 촬영 품질에 따른 자동 사진 추천, 리깅·걷기 애니메이션, 실제 이동 기록의 시간축 재생은 이번 범위에 포함하지 않았다. 현장 사진은 참고 카드이며 메시 텍스처로 사용하지 않는다.

- 정리 보기에는 실제 인물을 배치한다. 이번 요청의 시안에 맞춰 경로는 어두운 받침이 있는 아이보리 점선·화살표, 중간 지점은 초록, 무대 범위와 선택 기물 범위는 브론즈를 유지한다. 기존 스캔 메시/주석 및 안내 판정은 유지한다.
- 사진 촬영 위치를 켜면 검은 영사기가 저장된 카메라 방향으로 표시된다. 영사기를 선택하면 렌즈를 시작점으로 촬영 화각의 테두리가 나타난다. 영사기·테두리·1인칭 화면은 동일한 카메라 좌표 변환을 사용한다.
- 사진 목록 또는 작은 사진 카드의 시점 보기 버튼은 별도의 비교 화면을 연다. 위에는 촬영 위치·방향에서 본 3D, 아래에는 실제 원본 사진을 같은 종횡비로 표시한다. 스캔/정리 전환을 제공하고, 비교 화면을 닫아도 원래 전체/동선 위 카메라 조작 상태를 유지한다. 촬영 시점에서는 인물·동선·영사기 주석을 숨겨 시야를 가리지 않는다.
- 지점 목록 아래 큰 설명 카드를 제거했다. 사진 촬영 위치 토글과 사진 목록을 바로 이어 배치한다.
- 새 사진은 같은 ARFrame의 카메라 내부 파라미터와 JPEG 회전 정보를 함께 저장한다. 촬영 앵커가 보정돼도 화각 정보는 보존한다. 사진 연결 변경에도 보존된다. 이전 저장 사진은 그대로 읽으며 위치·앞 방향을 사용하고, 화각/화면 회전은 근사값임을 화면에 표시한다. 새 사진의 렌즈 왜곡까지 재현하는 기능은 아니다.

검증: 코어 XCTest 175개 통과(화각 회전, 저장 왕복/이전 사진 호환, 잘못된 보정 정보 거부 포함). 실제 SceneKit 검증에서 가로/세로 이미지의 네 모서리·광학 중심 재투영, 영사기/인물 번들 로딩, 촬영 시점 비교, 레이아웃 변경, 기본 카메라 복귀, 기존 스캔/정리 회귀가 통과했다. Debug Simulator 및 서명 제외 iPhone Release 빌드 확인. `--replay-comparison`으로 합성 사진과 검증용 공간의 비교 화면을 열 수 있다. 실제 기기 AR 촬영의 정합 검증은 별도로 필요하다.
