## 포함한 기능

- 원본 스캔 / 원목 바닥·웜그레이 기물의 정리 보기, 전체·동선 위 카메라, 시점 초기화 및 바닥 아래 회전 제한.
- 인물·출발/도착·경로·기물 표현, 실제 모델과 리깅된 걷기 인물.
- 준비·스캔 중 수동 사진 촬영, 이미지·위치·방향·화각 저장, 기물/경로 지점 연결, 영사기 방향과 사진/1인칭 3D 비교.
- 안내 중 실제 위치·몸 방향의 관찰용 기록, 표준 경로와 실제 궤적 비교, 재생/정지·배속·시간 탐색·주요 순간 표시.
- 기존 사진 없는 저장 공간과 위치 기록 없는 완료 기록의 호환성.

## develop 동작 보존 확인

- 공통 조상 이후 develop만 수정한 **34개 경로**는 삭제 상태까지 바이트 단위로 일치한다.
- `Core/Audio`, 코어 `Signal`, `Features/SoundTest`, Home, Planning에는 develop 대비 변경이 없다.
- `GuidanceViewModel.swift`, `+Guiding.swift`, `+Finish.swift`에서 추가된 `captureReplay` 호출만 제거하면 develop 원본과 정확히 일치한다. 관찰 코드는 안내 결정에 사용되지 않는다.
- 최신 좌우 발화와 거리 음성 중단 처리, 정렬음·도착음, 착용 완료로 즉시 다음 단계 진행하는 흐름을 유지한다.
- 삭제된 카운트다운·상호작용 설정·몸/고개 소리 실험 파일과 Xcode 참조를 복원하지 않았다.
- 전체 21개 경로점 제한, 저장 실패 시 입력을 보존하는 복구 UI·재시도 처리를 유지한다.
- 새 사진 앵커가 아직 지도에 반영되지 않은 경우에도 기존 `awaitSaveRecovery` 흐름을 사용한다. 검토 화면의 확인점 표시를 유지하며 사진 수만 추가한다.
- Xcode 프로젝트는 최신 develop 파일 트리에 새 기능을 합친 상태에서 재생성했다. 기존 작업 폴더의 개인 서명 설정은 옮기거나 수정하지 않았다.
- 원본 #52에 #48 전용 커밋이 없음을 확인했으며 통합 브랜치 역시 최신 develop에서 새 커밋으로 구성한다.
