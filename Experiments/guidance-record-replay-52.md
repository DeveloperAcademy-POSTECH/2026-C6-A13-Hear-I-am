## 저장

안내 출발부터 마지막 지점 도착까지, 검증된 최신 AR 위치와 몸 방향을 기본 0.2초 간격으로 저장한다. 위치는 표준 경로와 같은 무대 바닥 좌표이며, 방향·현재 목표·안내 상태도 함께 남는다. 상태나 목표가 바뀌면 간격을 기다리지 않는다. 위치 추적이 확인되지 않은 시간에는 좌표를 저장하지 않는다.

시간은 단조 증가 시계를 사용한다. 재생 길이에는 일시정지와 현장 재확인이 포함되며, 기존 `activeSeconds`는 안내 중 시간만 계산한다. 도착 안내가 끝나고 사용자가 종료할 때 기존 완료 기록 저장 흐름에 함께 저장한다. 중도 취소 기록은 만들지 않으며 재시도는 동일 세션 ID로 중복 저장을 막는다. 신호음, 경로 이탈 판정, 도착 판정, 복귀 안내의 규칙은 변경하지 않았다.

새 기록은 version 2이며, version 1의 기존 기록은 그대로 읽힌다. 옛 기록에 실제 이동선을 생성하지 않는다. 기록은 앱 내부에만 저장하며 원본 공간을 수정하거나 지워도 기록의 무대·경로 스냅샷은 유지된다.

최대 72,000개 샘플(기본 간격으로 약 4시간)을 저장한다. 상태 변화 샘플에 따라 더 일찍 한도에 도달할 수 있다. 한도 이후는 미기록 구간으로 표시하고 기록이 잘렸음을 알린다.

## 화면

- 전체 / 동선 위에서, 카메라 초기화, 기존처럼 바닥 아래로 내려가지 않는 회전 제한.
- 갈색 원목 바닥과 저장된 기물. 원본 메시를 복제하지 않고 저장된 무대·경로로 재구성한 공간임을 설명.
- 표준 경로는 밝은 점선, 실제 이동은 파란 실선. 재생한 부분은 진하게, 이후는 옅게 표시.
- 제공된 리깅 인물이 위치와 몸 방향을 따라 걷는다. 발걸음은 기록 속도에 맞춘 시각적 표현이며 실제 발걸음·시선 측정값은 아니다. 표시 높이는 저장된 경로 높이를 보간하며 실제 발 높이 측정값이 아님.
- 재생 / 일시정지 / 처음으로 / 0.5·1·2배속. 바를 끄는 동안 정지하고, 이전에 재생 중이면 손을 놓을 때 이어 재생. 백그라운드나 화면 이탈 시 정지.
- 현재 목표·상태·경로에서의 거리·몸 방향. 요약은 안내 시간 / 추정 이동 / 최대 이격 세 항목.
- 출발, 지점 도착, 일시정지, 경로 이탈, 추적 중단·재개 등 주요 순간을 누르면 해당 시간으로 이동.
- 이격은 표준 경로 전체에서 가장 가까운 선분까지의 거리. 이 값 자체를 기존 경로 이탈 판단으로 사용하지 않음.
- 거리에는 AR 추적 오차가 포함된다. 추적 공백, 0.75초보다 긴 샘플 간격, 비정상 위치 점프는 연결하거나 거리로 합산하지 않음. 미기록 구간에서는 인물을 숨김.
- 연결된 선분은 하나의 메시로 묶고 재생된 범위만 갱신. 시간 탐색은 이진 검색, 요약은 화면 진입 시 한 번 계산.

## 실제 기기 확인

1. #52 브랜치에서 저장된 공간을 복원하고 기존과 같은 방식으로 안내를 시작한다.
2. 출발→중간 지점→마지막 도착까지 이동한다. 안전한 장소에서 잠시 정지 후 재개도 확인한다.
3. 도착 안내 후 종료해 기록을 저장하고 기록 탭에서 새 항목을 연다.
4. 실제 이동선과 표준 경로를 비교하고 바를 앞뒤로 움직여 인물 위치·방향·현재 목표가 맞는지 확인한다.
5. 재생·일시정지·배속·주요 순간 이동, 전체→위→전체 전환 및 시점 초기화를 확인한다.
6. 위치 추적이 끊겼다가 재확인된 기록에서 공백을 가로지르는 선이나 인물이 생기지 않는지 확인한다.
7. 앱 재실행 후 새 기록이 유지되고, 기존 기록에는 실제 이동 재생 대신 저장 동선과 기존 요약이 표시되는지 확인한다.

## 리깅된 걷기 인물 (2026-10-21)

- 사용자 제공 `human+figure+3d+model.glb`를 사용. 앞서 제공한 정적 `인간+걷기.glb`는 사용하지 않는다.
- 원본 SHA-256: `05834b4477cb6e539ff9c647b217c5a1e6427a5ef6c23854b936d642abd64e0e`.
- 10,389 삼각형·11,398 정점·65개 Mixamo 관절과 가중치를 네이티브 SceneKit 스킨으로 보존했다. 2K 텍스처와 애니메이션 트랙을 포함하며 새 런타임 라이브러리는 없다.
- 재현: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift scripts/convert-replay-walker.swift <원본.glb> Hear-I-am/Resources/ReplayModels.scnassets`.
- 원본 클립 `swagger`는 약 3.67초. 팔을 가슴까지 드는 스타일이므로 사용자의 요청에 따라 팔을 몸 옆으로 내리고 팔·손목·상체 움직임을 줄였다. 고개는 중립 자세를 기준으로 작은 움직임만 유지한다. 별도 시선 추정은 하지 않는다.
- 17/24초부터 46/24초까지의 반복 구간(약 1.208초, 정규화 후 1.349m)을 사용한다. 마지막 0.10초의 작은 자세 차이를 연결한다. 키프레임의 회전은 quaternion 보간, 위치·크기는 원본 LINEAR/STEP을 따른다.
- 클립의 수평 루트 이동은 제거한다. 실제 위치·몸 방향은 기존 기록 좌표에서만 가져오며, 표시 높이는 기존 저장 경로 높이 계산을 유지한다.
- 경과 거리로 동작 주기를 계산하되 저속에서는 보폭을 줄인다. 0.08m/s 미만의 미세 움직임은 보행 주기에 더하지 않는다. 이는 시각적 보정이며 저장 기록·거리 요약·안내 판정에는 영향을 주지 않는다.
- 실제 정지 구간에서는 걷기 평균 자세를 바탕으로 팔을 내린 정지 자세로 전환한다. 일시정지 버튼은 그 시각의 자세를 고정한다. 재생 배속과 앞뒤 시간 탐색은 동일 타임라인을 사용하므로 자세가 따로 흘러가지 않는다.
- 추적 공백과 비정상 위치 점프에는 발걸음을 생성하지 않는다. 모델을 불러오지 못하면 기존 정적 인물을 사용한다. 플레이어마다 독립된 스킨을 읽어 다른 기록의 뼈대가 함께 움직이지 않게 한다.
- #49 공간 보기의 정적 인물·사진 영사기·스캔 보기와 기존 안내 신호 체계는 변경하지 않았다.
