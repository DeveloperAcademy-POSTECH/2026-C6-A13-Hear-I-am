## 연습과 실전

### 연습

1. 선택한 저장 무대와 **같은 실제 공간**의 임의 위치에서 휴대폰으로 주변을 천천히 비추며 제자리에서 한 바퀴 돈다.
2. 저장 월드맵 재인식이 확인되면 확인점 1/2를 찍지 않고 착용 단계로 간다. 임의의 다른 장소를 저장 공연장처럼 바꾸는 기능은 아니다.
3. 허리 앞쪽에 세로로 착용하고 후면 카메라를 몸 바깥으로 향하게 한다.
4. ‘출발’ 또는 안내 시작 버튼을 누르면 **그때의 현재 위치에서 실제 이름이 P1인 지점**으로 시작한다. 저장 출발점으로 되돌아가지 않는다. 앞에 의자·계단 지점이 있어도 배열의 1번 항목을 P1로 오인하지 않는다.
5. 현재 위치→P1의 직선이 저장된 스캔 범위 안이고 등록 기물과 충돌하지 않는지 확인한다. 자동 우회는 계산하지 않는다. 시작할 수 없는 경우 사유를 안내한다.
6. P1 이후에는 저장 동선의 기존 이동·방향·대기·복귀 안내를 사용한다. 이동 중 호출어로 요청할 수 있다.
7. 추적 중단 후 공간을 다시 찾으면 진행하던 목표와 방향 맞추기·대기 상태를 유지한다. P1부터 초기화하지 않는다.

### 실전

- 공연자가 실전용을 선택하거나 조력자가 공연 상세의 **무대 카드 오른쪽 ‘안내 시작’**을 누르면 같은 준비 흐름으로 진입한다.
- 조력자가 공간을 재인식하고 확인점 1→확인점 2를 맞춘다. 착용 후 저장 출발점을 준비해 시작한다.
- 조력자 준비는 버튼으로 진행한다. 실제 이동 중에는 마이크를 닫고 이동 안내 출력만 유지한다.
- 공연자가 실전 준비를 취소하면 원래 공연/무대 선택 맥락과 음성 입력을 복원한다. 실제 조력자 진입의 마이크 상태와 구분한다.
- 이동 화면은 연습 흰색/실전 검정으로 구분한다. 진행률·방향·거리·목표·마이크 상태·일시정지를 표시한다.
- develop의 신호·거리 안내·기물 경고·도착 조건은 유지한다. #48의 별도 신호 실험을 이 브랜치에 가져오지 않는다.

## 스캔과 저장 후 분류

1. 기존 스캔·경계·기물·동선·확인점 준비 흐름을 유지한다. 기본 동선 불러오기도 유지한다.
2. 마지막 ‘무대 정보를 확인해주세요’에서는 이름 입력을 제거하고 돌아가기/저장하기를 사용한다.
3. 날짜를 포함한 기본 이름으로 원본 스캔을 먼저 저장한다. 실제 저장된 ID를 다음 화면에 전달한다.
4. 저장 성공 후 공연 폴더와 공연장 태그를 선택하거나 생성한다. 저장 무대 이름은 분류 화면에서 필요할 때 수정할 수 있다.
5. 분류를 나중으로 미루거나 창을 닫아도 저장본은 남는다. 공연 관리의 미분류 무대에서 이어서 정리한다.
6. 분류 완료 후 저장한 공연으로 이동하거나 공연장 태그를 관리할 수 있다.

## 공연 폴더와 기본 동선

- 상단 오른쪽 +로 공연 폴더를 만든다. 공연 이름/설명을 입력하며 목록 검색·정렬·편집을 지원한다.
- 공연 상세 상단에는 이름/설명, 아래에는 기본 동선 카드와 세로형 편집 화면, 공연장별 저장 무대를 둔다.
- 기본 동선에서 출발·경유·도착, 기물의 위치·크기, 의자 방향, 지점 이름·대기·바라볼 방향을 설정한다.
- 기본 동선은 공연의 기준 계획이다. 수정했다고 이미 저장된 실제 무대 경로를 자동 변경하지 않는다.
- 공연장 태그를 가로로 선택해 해당 저장본을 본다. 같은 공연장에 여러 저장본을 둘 수 있다.
- 무대 카드 본문은 정리된 보기로 열린다. 전체/위에서 보기, 사진 비교, 경로점 설정은 유지한다. 원본 스캔/정리 보기 전환은 제거했다.
- 공연장 태그의 중복 이름을 검사하고 이름 변경/삭제, 여러 무대의 일괄 재분류를 지원한다. 태그 삭제는 공연장 미지정으로, 공연 폴더 삭제는 미분류로 옮긴다. 원본 스캔·사진·기록은 삭제하지 않는다.

## 저장과 이전 호환

- 분류 데이터는 `Documents/Performances`에 별도로 저장한다. 기존 `Scans`, `PerformancePlans`, `GuidanceRecords`, 고정 목록을 보존한다.
- 최초 이전은 성공적으로 읽은 기존 스캔·장소·동선을 한 번만 분류한다. 기존 장소의 주소·사진·빈 하위폴더·고정 정보는 이전 메타데이터에 보존한다.
- 같은 이름의 독립 기본 동선도 잃지 않도록 구분해 이전한다. 재실행해도 중복 폴더를 만들지 않는다.
- 구형 기본 동선과 안내 기록은 새 필드가 없어도 읽는다. 손상 파일을 빈 데이터로 덮어쓰지 않고 오류를 표시한다.
- 연습의 임시 첫 구간은 저장 무대 경로를 바꾸지 않는다. 안내 기록에서는 실제 시작 지점/구간에 맞게 도착 수와 재생 분석을 계산한다.

### 실제 기기에서 확인할 항목

- 같은 공간에서 제자리 회전으로 재인식되는지, 조명·시야가 달라질 때 걸리는 시간과 정확도.
- 확인점 없이 허리 착용 후 현재 위치→P1로 시작하는지, 스캔 경계/기물로 시작이 제한될 때 문구가 적절한지.
- P1 이후 목표를 진행한 뒤 중단·재인식했을 때 목표/대기/복귀가 유지되는지.
- 실전 두 진입에서 확인점 1/2와 출발점 준비가 필수인지, 시작 후 마이크가 닫히는지.
- AirPods 한쪽 사용 시 기존 신호와 음성 겹침·호출어·음성 인식 정확도.
- 실제 LiDAR 스캔→저장→공연/태그 분류→재실행→사진/동선/기록 유지.

시뮬레이터의 UI용 샘플은 실제 AR 월드맵이 아니므로 실제 공간 정합성의 검증 결과로 취급하지 않는다.
