## 화면 구성

홈 상단 설정 버튼에서 전체 설정 페이지로 이동한다. 설정과 하위 화면에서는 탭바를 숨기고, 홈으로 돌아오면 홈·장소·공연 사전 저장·기록 4개 탭을 다시 표시한다. 기존 신호 튜토리얼 탭은 제거했다.

설정의 안내 신호 익히기에서 원하는 단계를 바로 선택한다. 단계 안의 이전·다음으로 이동하며 마지막 단계에서는 목록으로 돌아온다. 첫 단계의 이전은 비활성화한다. 별도의 ‘처음부터 함께 시작’·‘필요한 신호만 듣기’ 버튼은 두지 않는다.

소리 출력은 기존 `audio.forceSpeaker` 설정을 이어서 사용한다. 연결된 기기로 자동 출력하거나 항상 iPhone 스피커로 출력하도록 선택하며, 현재 출력 기기와 시험 소리를 제공한다. 기존 음량·음색·출력 정책은 공용 오디오 구현을 사용한다.

착용과 안내 준비, 소리가 들리지 않을 때, 권한 상태, 앱 정보는 ‘준비 중’으로 표시한다. 이동 버튼이나 화살표는 붙이지 않았다.

## 기존 항목 이관

기준 develop의 신호 튜토리얼에 있던 23개 미리듣기를 모두 유지한다. 공용 `SignalCopy`, `GuidanceCopy`, `SignalPlayer`, `GuidanceSpeech`를 사용하며 실제 무대 안내 규칙과 AR 스캔·저장·기록 처리는 변경하지 않았다. #48·#69의 실험 신호나 음성인식은 가져오지 않았다.

| 단계 | 이관한 재생 항목 | 수 |
| --- | --- | ---: |
| 1 듣기 준비 | 출발 준비 완료 띵 | 1 |
| 2 방향 찾기 | 왼쪽/오른쪽 톡, 다음 지점 방향 좌/우, 방향이 틀렸을 때 좌/우 | 6 |
| 3 방향 맞춤과 거리 | 현재 저장된 방향 맞음 음색, 3m·2m·1m·0.5m 거리 음성 | 5 |
| 4 출발·도착·대기 | 출발, P1·P2 도착, 띵+완료, 완료 음성만 | 5 |
| 5 의자와 계단 | 의자·계단 사전 안내, 의자1·계단1 도착, 도착 후 좌/우 바라보기 | 6 |

다음 지점 방향 음성은 기존의 더 큰 음량을 유지한다. 마지막 지점 미리듣기는 기존과 같이 띵 시작 0.7초 뒤 완료 음성을 재생한다. 공연 대기는 현재 안내 동작에 대한 설명만 제공하며 새 신호음은 추가하지 않는다.

## 재생과 접근성

- 재생 항목을 다시 누르면 중지하고, 다른 항목을 누르면 이전 재생을 중지한다.
- 단계 이동·뒤로 가기·백그라운드 전환·오디오 중단 시 소리와 예약 음성을 취소한다.
- 이어폰 연결/해제 시 기존 미리듣기를 멈춘다. 사용자가 다음 항목을 눌러 새 출력에서 확인한다.
- 출력 설정 변경 시 미리듣기를 정리하고 기존 오디오 세션 설정을 적용한다.
- 단계 설명은 사용자가 ‘설명 듣기’를 누를 때 읽는다. 화면 진입 시 자동 재생하지 않는다.
- VoiceOver에 단계 번호, 항목 이름, 듣기/중지, 재생 상태를 제공한다. 단계 이동 후 제목으로 접근성 초점을 이동한다.
- 큰 글씨에서 문구가 줄바꿈되며 준비 중 행은 세로 배치로 바뀐다. 이전·다음은 하단에서 계속 접근 가능하다.

## 실제 기기에서 확인할 사항

1. 홈의 설정을 열고 3번부터 들어간 뒤 이전·다음·목록 복귀를 사용한다.
2. 각 단계의 신호를 듣고 다른 신호나 설명으로 전환한다. 완료 미리듣기 직후 다음/뒤로 가기로 이동해 늦은 음성이 남지 않는지 확인한다.
3. 이어폰 없이 자동 출력을 듣고, 이어폰 연결 상태에서 자동/스피커를 전환한다. 시험 소리가 표시된 기기로 들리는지 확인한다.
4. 재생 중 이어폰 해제·앱 전환·전화 중단 뒤 새 항목을 눌러 재생한다.
5. VoiceOver를 켜고 목록, 재생/중지, 이전/다음의 이름·읽기 순서·초점 이동을 확인한다. 앱의 설명 읽기와 VoiceOver 청취 사용감은 실제 기기에서 확인한다.

## 추가: 정면 찾기 연습 (2026-10-27)

`안내 신호 익히기 → ② 방향 찾기 → 정면 찾기 연습`에서 실행한다. 기존 미리듣기 23개는 유지하고 별도 실습을 추가했다.

1. 휴대폰을 실제 안내 때처럼 몸에 고정하고 조력자와 정면을 정한다. 최신 유효 방향 입력을 받은 뒤에만 정면 지정 버튼이 활성화된다.
2. ‘이 방향을 정면으로 지정’을 누른다. 지정 직후에는 성공 판정하지 않는다.
3. 제자리에서 몸을 좌우로 돌린다. 정면에서 충분히 벗어나면 기존 방향 안내를 재생한다.
4. 돌아올 방향을 한 번 읽은 뒤 좌우 톡을 재생한다. 현재 `DirectionTickGate`의 좌우 구분·각도별 간격과 저장된 정렬 허용 범위를 사용한다. 3→2→1 횟수 규칙은 추가하지 않았다.
5. 정면에 돌아오면 현재 방향 맞음 음색을 한 번 재생하고 ‘방향이 맞았어요. 지정한 정면으로 돌아왔어요.’라고 읽는다. 같은 기준으로 다시 연습하거나 정면을 다시 지정할 수 있다.

### 구현과 중단 조건

- Core Motion의 `xArbitraryZVertical`과 기존 `HeadingMath.screenHeadingDegrees`로 휴대폰의 상대 회전을 사용한다. 카메라, AR 스캔, 위치 권한, 이어폰 고개 센서는 사용하지 않는다.
- 신호음과 음성은 기존 `SignalPlayer`·`GuidanceSpeech`를 사용한다. 실제 무대 안내 코드는 수정하지 않았다.
- 기본 정렬 허용 범위는 12도이며 저장된 설정을 따른다. 실습 시작을 위한 이탈 기준은 `max(25도, 정렬 허용 범위 + 13도)`로, 가벼운 흔들림이 실습 시작/성공으로 잡히지 않게 한다.
- 휴대폰이 누워 수평 방향을 구할 수 없으면 기준을 해제하고 착용 자세를 다시 잡게 한다. 시작 후 3초간 입력이 없거나 마지막 입력이 1.5초 넘게 끊기면 중지한다.
- 화면 이탈·앱 비활성화·소리 중단·이어폰 연결 변경 시 센서와 소리를 중지하고 기준을 해제한다. 새 센서 세션의 좌표를 이전 기준과 섞지 않는다. 늦게 도착한 이전 세션 입력/성공 음성도 취소한다.
- 완료 후 ‘다시 연습’은 같은 센서 세션의 정면을 유지한다. ‘정면 다시 지정’은 이전 기준을 지운다. 이 기준은 저장된 무대나 공연 데이터에 기록하지 않는다.
- `NSMotionUsageDescription`을 실제 몸 방향 연습 용도로 정리했다. 사용자 로컬 서명 설정은 보존하고 제외했으며 새 파일 등록과 사용 설명만 프로젝트 커밋에 포함했다.
- API 참고: [Apple CMMotionManager](https://developer.apple.com/documentation/coremotion/cmmotionmanager), [device motion 시작·종료](https://developer.apple.com/documentation/coremotion/cmmotionmanager/startdevicemotionupdates()).
