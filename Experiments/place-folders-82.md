# 장소별 공연 폴더 관리 (#82)

- 작업 브랜치: `feat/#82-place-folders`
- 기준: `origin/develop`의 `70ce252486d1b2ec64ffbfe258ae8d1a71ea530a`
- 목적: 저장된 스캔 공연을 장소와 선택적 하위 폴더로 분류한다.
- #61의 기본 공간·운영자 카탈로그·추가 스캔 기능은 반영하지 않는다. 장소와 폴더 자체에는 스캔이 없다.
- 원격 브랜치 푸시까지 진행하며 PR은 생성하지 않는다.

## 화면과 동작

1. 기존 탭 사이에 **장소**만 추가한다. 홈·공연 사전 저장·기록·신호 튜토리얼은 유지한다.
2. 장소 제목 옆 원형 `+`: 이름, 위치, 사진, 연습장/공연장 유형을 등록한다. 하위 폴더는 선택 사항이다. 사진은 사진 보관함에서 고르고 최대 1200px JPEG로 앱 안에 보관한다.
3. 장소 홈: 검색 → 장소 미지정 한 줄 → 내 장소/정렬 → 전체·연습장·공연장/즐겨찾기 → 사진 카드. 오른쪽 아래 **새 스캔**은 폴더 없이 기존 준비 화면을 연다.
4. 장소 및 하위 폴더: 해당 폴더의 공연, 이름 변경·즐겨찾기·이동, 기존 3D 다시보기를 제공한다. 여러 공연을 선택해 한 번에 이동할 수 있다. 장소 바로 아래에도 공연을 저장할 수 있다.
5. 폴더 안의 **새 공연 준비**: 기존 `PreparationView`를 그대로 연다. 이름 입력·스캔·기물·동선·저장 순서는 기존 화면을 따른다. 새로 저장한 공연만 시작한 폴더에 연결한다.
6. 검색: 장소명·주소·하위 폴더명·공연명을 대상으로 한다. 장소 검색은 장소와 그 안의 공연을 함께 표시한다. 공연명 검색은 UUID별 결과를 유지하며 장소·폴더·저장일을 표시한다. 검색은 장소 목록 필터와 독립적이다.
7. 장소 삭제 또는 하위 폴더 제거: 공연을 장소 미지정으로 돌린다. 스캔·동선·사진·안내 기록은 삭제하지 않는다.

접근성 글씨 크기에서는 사진 썸네일보다 이름과 위치를 우선하며, 목록 헤더를 세로로 배치하고 유형 선택을 메뉴로 전환한다. 아이콘 전용 버튼은 44pt 터치 영역을 유지한다.

## 저장과 기존 자료 보존

- 새 분류 정보는 `Documents/PlaceFolders/places.json`, 장소 사진은 `PlaceFolders/photos/<UUID>.jpg`에 저장한다.
- `ScanManifest`와 `ScanStore`는 변경하지 않는다. 기존 스캔에 분류 정보가 없으면 **장소 미지정**으로 보인다. 기존 스캔의 마이그레이션·이동·복사는 하지 않는다.
- 장소/폴더 삭제는 분류만 해제한다. 사진 교체는 새 사진과 색인 저장 성공 후 이전 사진을 정리한다. 손상되거나 지원하지 않는 색인은 덮어쓰지 않는다.
- 공연 이름 변경은 기존 `StageLibrary.renameStage`를 이용한다. 장소 탭의 즐겨찾기는 홈의 고정 설정과 별도로 저장한다.
- 폴더에서 스캔을 열기 직전 기존 스캔 ID와 시작 시간을 기록한다. 닫힐 때 새 ID가 하나이며 시작 이후 저장됐을 때만 분류한다. 취소·여러 새 저장·연결 오류에는 기존 자료를 변경하지 않는다.
- 스캔 저장 후 폴더 연결 전에 앱이 종료되면 원본은 보존되고 장소 미지정에 남는다. 다음 실행에서 사용자가 이동할 수 있다. 오래된 임시 세션을 복원해 다른 스캔을 잘못 분류하지 않는다.
