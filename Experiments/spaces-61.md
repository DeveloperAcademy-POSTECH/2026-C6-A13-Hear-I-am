2026-10-22 공식 안내를 기준으로 작성했다. 카탈로그 원본과 사진별 출처는 `Packages/HearIAmCore/Sources/HearIAmCore/Spaces/Resources/venues.json`에 있다. 객석 필터는 서비스 기준(300석 미만/300–999석/1,000석 이상)이며, 공연장의 공식 이름이나 무대 면적 분류와 구분한다. 대명홀은 연습 공간으로 분류했다.

사진은 공식 페이지에서 연결한 실제 사진을 불러온다. 대구 연습공간과 수성아트피아는 내부 사진, 나머지 네 장소는 외관 사진으로 명시했다. 최초 로딩에는 네트워크가 필요하며 이후 다운샘플한 사진을 메모리·디스크에 캐시한다. 실패 시 재시도와 출처 링크를 제공한다. 앱에 원본 사진을 번들로 넣지는 않았다.

**공식 장소 정보가 있다는 것과 사용 가능한 AR 기본 스캔이 있다는 것은 다르다.** 최초 설치 카탈로그에는 실제 기본 스캔을 포함하지 않는다. 스캔이 없으면 `공간 정보만 등록됨`/`기본 공간 미등록`으로 표시하며, 전체 스캔으로 새 공연을 준비할 수 있다. 기존 저장 무대는 삭제·변환하지 않고 미연결 목록에 남기며, 해당 내부 공간에 연결할 수 있다.

## 기본 공간 등록과 공연 준비

현재는 같은 iPhone으로 준비하고 공연자에게 전달하는 범위다. 기본 공간을 다른 기기로 배포하는 서버, 운영자 계정·권한 시스템, 사용자 공개 등록 요청은 구현하지 않았다.

1. Xcode Debug 빌드의 **공간 탭 → 오른쪽 위 메뉴 → 운영용 기본 공간 등록**을 켠다. 내부 공간 하단에 `기본 공간 새 버전 등록 · 운영용`이 나타난다. 이 메뉴는 내부 현장 시험 도구이며 사용자 인증 기능이 아니다. Release에서는 숨긴다.
2. 이동할 기물을 치운 실제 공간을 LiDAR로 스캔한다. 방의 기준 사각 범위와 다시 찾을 바닥 확인점 C를 지정한다. 저장할 때 C 위치 설명을 적는다. 기본 공간에는 공연 동선을 넣지 않는다.
3. 내부 공간에서 `이 공간으로 새 공연 준비 → 저장된 기본 공간 사용`을 선택한다. 저장된 ARWorldMap을 복원하고, 안내된 실제 표식에 십자선을 맞춰 확인점을 검증한다. 복원 후보만으로 다음 단계로 넘어가지 않는다.
4. 위치 확인 후 같은 ARSession의 좌표계를 유지한다. 이번 공연의 범위를 기본 공간 내부·같은 바닥에 새로 지정한다.
5. 추가 기물이 있다면 바닥 둘레를 3–8개 점으로 지정하고 `둘레 안 추가 스캔`을 누른다. 여러 각도에서 표면을 담은 뒤 기물 종류·출입 변 등을 확인해 등록한다. 높이는 수집한 메시로 측정한다. 둘레가 바뀌면 재촬영이 필요하며 이름 등 속성만 바꾸는 경우 메시를 유지한다.
6. 동선, 이번 공연의 C, 필요한 사진을 준비하고 공연 이름으로 저장한다. 내부 공간의 내 공연에서 3D 보기·안내·해당 공연의 기록으로 연결한다.

기본 공간 재등록은 새 UUID의 버전으로 저장한다. 최신 버전을 기본으로 제시하며 이전 버전도 조회·선택할 수 있다. 각 공연에는 사용한 기본 버전 ID·메시 해시와 합성된 메시·공간 지도·사진을 독립 저장한다. 원본 기본 공간이나 다른 공연을 덮어쓰지 않는다. 기존 기본 공간을 삭제해도 이미 저장한 공연의 자체 스냅샷은 읽을 수 있다.

## 추가 스캔의 기술적 범위

완전 자동 차이 검출이나 전체 재메시가 아니다. 사용자가 지정한 기물 둘레 안에서 명시적으로 수집한 표면을 공연 사본에 합성한다. 저장된 옛 ARMeshAnchor는 초기 지도에서 제외하고, 원본 메시 스냅샷은 별도로 보존한다.

- 추가 스캔은 LiDAR와 정상 위치 추적이 필요하다. 기본 공간 복원도 LiDAR 기기를 대상으로 한다.
- 평면 자체를 덮지 않도록 바닥 위 3.5cm를 넘는 표면이 있는 삼각형만 수집한다. 바닥에 닿은 옆면은 포함하며 상한은 2.5m다.
- 삼각형의 정점·중점·중심이 모두 둘레 안에 있을 때만 선택한다. 경계에 걸친 면은 보수적으로 제외하므로 가장자리의 미세한 빈틈은 생길 수 있다.
- 기물별 둘레 중첩은 허용하지 않는다. 선택 범위 내 기존 바닥 위 표면만 제거하고 새 기물 레이어를 추가한다. 사용자가 담지 않은 공간의 구멍을 자동으로 채우지 않는다.
- 추가 스캔 15만 정점, 합성 결과 80만 정점을 넘으면 진행을 제한한다. 표면 선택과 등록 시 합성은 UI 스레드 밖에서 수행한다.
- 추적 중단/백그라운드/취소 시 미확정 추가 스캔을 폐기한다. 이미 확정한 기물과 준비 입력은 유지한다.
- C 허용 오차 등 기존 위치 검증 기준을 사용한다. 하나의 C 확인으로 공간 전체의 정확도가 보장되는 것은 아니며, 실제 기기 검증은 아직 수행하지 않았다.
